DESCRIPCIÓN DEL PROYECTO
========================
ThreatGuard es una plataforma empresarial de ciberseguridad para SOCs (Security 
Operations Centers) que combina:
- Detección de amenazas en tiempo real (IDS con Snort 3)
- Análisis con Machine Learning
- Gestión de vulnerabilidades (OpenVAS)
- Automatización SOAR

COMPONENTES TÉCNICOS:
- API Backend (Python/FastAPI) - Puerto 9000
- Frontend Web (HTML/CSS/JavaScript) - Puerto 3000
- PostgreSQL/MySQL - Puertos 5432/3306
- Snort IDS, Redis, OpenVAS

                   ESPECIFICACIONES TÉCNICAS

FRAMEWORK: Electron 28.3.3
- Node.js integrado
- Chromium embebido
- IPC (Inter-Process Communication) para backend-frontend

ESTILOS: CSS puro sin frameworks
- No Tailwind, no Bootstrap
- Custom properties (CSS variables) para colores
- Flexbox y Grid para layouts
- Media queries limitadas (ventana fija)

COMPATIBILIDAD:
- Windows 10/11 exclusivamente
- Permisos de administrador requeridos
- Detección automática de servicios Windows
- PowerShell para comandos del sistema

ARCHIVOS PRINCIPALES:
- installer/installer-app/src/renderer/index.html (Estructura)
- installer/installer-app/src/renderer/styles.css (Estilos)
- installer/installer-app/src/renderer/installer.js (Lógica)
- installer/installer-app/src/backend/windows-installer.js (Backend)

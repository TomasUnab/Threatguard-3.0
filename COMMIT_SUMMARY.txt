COMANDOS PARA SUBIR:
--------------------
Windows:

Linux/Mac:
  git add .
  git commit -m "feat: Sistema completo de reportes, políticas Snort y mejoras UI"
  git push origin master

VERIFICACIÓN POST-PUSH:
-----------------------
1. Verificar en GitHub que todos los archivos se subieron
2. Clonar en otra máquina para probar instalación limpia
3. Ejecutar: docker-compose up -d --build
4. Verificar funcionalidades nuevas

NOTAS IMPORTANTES:
------------------
⚠️ NO subir archivos .ini con credenciales reales
⚠️ NO subir modelos .pkl (son muy grandes)
⚠️ Verificar que .gitignore esté funcionando

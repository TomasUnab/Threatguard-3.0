# Assets para ThreatGuard Agent

## Archivos necesarios:

### icon.ico
Icono de la aplicación (256x256 px)
- Usar herramienta: https://www.icoconverter.com/
- Diseño: Escudo con colores azul/verde

### Crear icono simple:
1. Crear imagen PNG 256x256
2. Convertir a ICO
3. Guardar como `icon.ico`

## Opcional (para instalador):
- installer-banner.bmp (164x314 px)
- installer-icon.bmp (55x58 px)
